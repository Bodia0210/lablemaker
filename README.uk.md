# KEL Label Maker

Вебдодаток для транспортних і складських етикеток Kehoe Equipment. Працює в браузері без встановлення залежностей і збирання.

![Label preview with synthetic demo data](docs/label-preview.jpg)

## Використання

1. Відкрийте **Product of** і позначте одного або кількох виробників. Усі вибрані логотипи з’являться на етикетці; зняття галочки прибирає відповідний логотип.
2. Кнопкою **+ Add package type** додайте рядки **Skid** (піддон), **Crate** (крейтовий ящик) або **Box** (коробка) з окремою цілою кількістю для кожного. Наприклад, 1 Skid + 1 Crate + 2 Boxes автоматично дає **Total pieces: 4**. Порожні рядки можна залишити незаповненими. Максимум — 100 місць загалом. Однакові типи об’єднуються в друкованому підсумку.
3. Введіть розміри кожної упаковки **W × L × H у дюймах**. Вони залишаються прив’язаними до свого рядка упаковки при зміні або тимчасовому очищенні кількості. Видалення рядка прибирає його розміри й зберігає дані інших рядків.
4. Натисніть **Generate Label**, щоб переглянути етикетку. **Edit details** повертає до редагування зі збереженням введених даних.
5. Натисніть **Print / Save PDF** і виберіть принтер або «Зберегти як PDF» у діалозі браузера. Ctrl/Cmd+P також формує етикетку з поточних даних.

Порожні необов’язкові поля не друкуються. Кнопка друку чекає завантаження всіх вибраних логотипів. Довгі етикетки можуть переходити на наступні сторінки без обрізання; остаточне розбиття залежить від принтера, формату паперу й налаштувань. Для чистої етикетки вимкніть колонтитули браузера.

Дані зберігаються в пам’яті, поки сторінку відкрито. Оновлення або закриття сторінки їх очищає. Серверна частина, обліковий запис і хмарне сховище не використовуються.

## Локальний запуск

```sh
git clone https://github.com/Bodia0210/lablemaker.git
cd lablemaker
python3 -m http.server 8000
```

Відкрийте <http://localhost:8000>.

## Перевірка змін

```sh
node --check scripts/main.js
git diff --check
```

У браузері перевіряйте створення й редагування етикетки, змішані типи упаковки, автоматичну загальну кількість, зміну кількості (зокрема очищення та відновлення), видалення упаковок, необов’язкові поля, кілька логотипів і друк. Довгий текст перевіряйте з потрібним принтером і форматом паперу.

## Структура

- `index.html` — форма з підписами полів і попередній перегляд.
- `scripts/main.js` — розміри місць, перевірка даних, формування етикетки й підготовка друку.
- `styles/styles.css` — адаптивна форма, оформлення етикетки та правила друку.
- `svg/` — наявні логотипи виробників і KEL.
